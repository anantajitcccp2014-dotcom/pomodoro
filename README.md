# Гхатика

Таймер работы и перерывов для Android. Гхатика — древнеиндийская мера времени в 24 минуты (и водяные часы-чаша, тонущие ровно за это время).

- циклы работа / перерыв, длинный перерыв после N циклов (гхатика 24/6, мухурта 48/12, 25/5, 50/10, 90/15 или свои значения);
- напоминание со звуком и вибрацией приходит и при выключенном экране;
- обратный отсчёт и кнопки «Пауза / Пропустить / Стоп» в шторке уведомлений;
- учёт рабочего времени: сегодня, неделя, последние 7 дней.
