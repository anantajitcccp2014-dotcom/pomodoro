# Помодоро

Простой таймер работы и перерывов для Android.

- циклы работа / перерыв, длинный перерыв после N циклов (25/5, 50/10, 90/15 или свои значения);
- напоминание со звуком и вибрацией приходит и при выключенном экране;
- обратный отсчёт и кнопки «Пауза / Пропустить / Стоп» в шторке уведомлений;
- учёт рабочего времени: сегодня, неделя, последние 7 дней.

## Скачать

APK собирается автоматически при каждом изменении кода.
Последняя версия: раздел **Releases** → `Pomodoro.apk`.
